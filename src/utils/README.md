# Dataset Utilities

This folder contains helper scripts for dataset preprocessing and organization.

| File | Purpose |
| --- | --- |
| `z_score.py` | Compute and apply z-score normalization using training-set statistics |
| `create_3ch_dataset.py` | Generate the 3-channel dataset from the 5-channel dataset |
| `split_data.py` | Split raw CSV files into train, validation, and test subsets |

Use these utilities when rebuilding the dataset or checking preprocessing assumptions.
